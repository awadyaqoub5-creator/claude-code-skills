الـ Hooks في Claude Code: أتمتة تشتغل لحالها

الـ Hooks أوامر تشتغل تلقائيًا عند أحداث معينة في Claude Code، مثل تنسيق الكود بعد كل تعديل أو منع تعديل ملفات حساسة.

تقدر تكتب في CLAUDE.md «نسّق الكود بعد كل تعديل»، وClaude غالبًا بيلتزم. بس «غالبًا» ما تكفي أحيانًا. الـ Hooks تضمن إن الشي يصير كل مرة، لأنها أوامر ينفذها Claude Code نفسه عند أحداث محددة، مو تعليمات يتذكرها Claude.

وش هي الـ Hooks؟

الـ Hook أمر شل (Shell Command) تربطه بحدث معين. لما يصير الحدث، الأمر يشتغل تلقائيًا. أشهر الأحداث:

الحدثمتى يصير
PreToolUseقبل ما Claude يستخدم أداة، مثل تعديل ملف أو تشغيل أمر
PostToolUseبعد ما يخلص استخدام الأداة
UserPromptSubmitلما ترسل طلب
Notificationلما Claude يرسل تنبيه، مثل إنه ينتظر موافقتك
Stopلما Claude يخلص رده
SessionStartلما تبدأ جلسة

وين تنضبط؟

الـ Hooks تنكتب في ملفات الإعدادات: ~/.claude/settings.json لكل مشاريعك، أو .claude/settings.json داخل المشروع. وتقدر تستخدم أمر /hooks داخل الجلسة عشان تشوفها وتديرها من واجهة أسهل.

مثال: تنسيق الكود تلقائيًا

هذا الإعداد يشغّل Prettier بعد كل مرة Claude يعدّل أو يكتب ملف:

{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [
          {
            "type": "command",
            "command": "npx prettier --write ."
          }
        ]
      }
    ]
  }
}

الـ matcher يحدد أي أدوات يشتغل معها الـ Hook. هنا اخترنا أدوات التعديل والكتابة بس، عشان ما يشتغل مع كل أمر.

منع أشياء ما تبغاها

مع حدث PreToolUse تقدر توقف العملية قبل ما تصير. الـ Hook يستلم تفاصيل الأداة بصيغة JSON، وإذا رجع برمز خروج 2 تنمنع العملية، والرسالة اللي يكتبها في stderr توصل لـ Claude عشان يفهم ليش انمنع. استخدامات شائعة:

  • منع تعديل ملف .env أو ملفات الإعداد الحساسة.
  • منع أوامر خطيرة مثل الحذف الكامل لمجلدات.
  • التأكد إن الاختبارات تمر قبل خطوات معينة.

وإذا تبغى مساعدة، اطلب من Claude نفسه يكتب لك الـ Hook:

اكتب لي Hook في .claude/settings.json يمنعك من تعديل
أي ملف اسمه .env أو داخل مجلد secrets،
واشرح لي كل جزء فيه قبل ما تضيفه.

أفكار سريعة

  • تشغيل فحص الكود (Lint) بعد كل تعديل.
  • تنبيه صوتي أو إشعار لما Claude يخلص أو ينتظرك.
  • تسجيل كل الأوامر اللي نفذها Claude في ملف.
أمان: الـ Hooks تشتغل بصلاحيات حسابك على الجهاز. لا تنسخ Hook ما تفهمه، وراجع أي إعداد قبل ما تضيفه، خصوصًا لو جاك من مشروع أحد ثاني.

ابدأ بـ Hook واحد بسيط مثل التنسيق التلقائي، وبعد ما تتعود عليه زِد على حسب احتياجك.
