سوّ موقعك مجاناً على GitHub Pages خطوة بخطوة

GitHub Pages يستضيف موقعك الثابت مجاناً من مستودع عام. هنا الطريقتين: من الإعدادات، أو بالأوامر مع Claude Code.

عندك صفحة HTML سويتها، أو موقع شخصي بسيط، وتبغى رابط تشاركه مع الناس بدون ما تدفع على استضافة؟ GitHub Pages يحل لك هالموضوع.

وش هو GitHub Pages؟

خدمة من GitHub تستضيف المواقع الثابتة مجاناً من مستودع عام. الموقع الثابت يعني ملفات HTML وCSS وJavaScript، بدون سيرفر وقاعدة بيانات. ورابط موقعك يكون بهالشكل:

https://اسم-المستخدم.github.io/اسم-المستودع

الشرح الرسمي موجود على pages.github.com.

قبل ما تبدأ

  • حساب على github.com.
  • ملفات موقعك، وأهمها ملف اسمه index.html في المجلد الرئيسي.
  • تأكد إن ما في ملفاتك أي معلومات خاصة، لأن المستودع عام والكل يقدر يشوفه.

الطريقة الأولى: من موقع GitHub

  1. سوّ مستودع جديد عام.
  2. ارفع ملفات موقعك، وتأكد إن index.html في الجذر.
  3. ادخل Settings ثم Pages.
  4. في المصدر اختار الفرع main والمجلد الرئيسي، واحفظ.
  5. انتظر دقائق، وبيظهر لك رابط الموقع في نفس الصفحة.

الطريقة الثانية: بالأوامر

لو عندك أداة GitHub في الطرفية وهي gh ومسجل دخولك فيها، تقدر تسوي المستودع وترفع الملفات من مجلد موقعك:

git init
git add .
git commit -m "first version"
gh repo create my-site --public --source=. --push

بعدها فعّل Pages من الإعدادات زي الطريقة الأولى. وتقدر تخلي Claude Code يسوي الخطوات عنك:

عندي موقع في هذا المجلد وأبغى أنشره على GitHub Pages.
1. تأكد إن index.html موجود في الجذر.
2. افحص الملفات وتأكد ما فيها مفاتيح أو بيانات خاصة.
3. سوّ مستودع عام باسم my-site وارفع الملفات.
4. اشرح لي كيف أفعّل Pages، وعطني رابط الموقع المتوقع.
استأذن مني قبل أي خطوة رفع.

تحديث الموقع ومشاكل شائعة

كل ما تعدّل وترفع التعديل للفرع اللي اخترته، الموقع يتحدث تلقائياً بعد شوي.

  • صفحة 404: غالباً index.html مو في المكان الصح، أو اسمه مكتوب غلط.
  • الصور ما تظهر: تأكد من المسارات، واستخدم مسارات نسبية مثل images/logo.png.
  • التغيير ما بان: انتظر شوي وحدّث الصفحة.
تذكير: GitHub Pages للمواقع الثابتة. لو موقعك يحتاج تسجيل دخول أو قاعدة بيانات، تحتاج حل ثاني.

خطوة إضافية: دومين خاص

لو عندك دومين، تقدر تربطه بموقعك من نفس صفحة Pages في الإعدادات، بعد ما تضبط إعدادات الدومين عند الجهة اللي اشتريت منها. التفاصيل موجودة في الشرح الرسمي على docs.github.com. وإذا ما عندك دومين، الرابط المجاني يكفي تماماً للبداية، وتقدر تحطه في البايو أو ترسله لعملائك.

وكل ما تبغى تعدّل، قول لClaude وش التعديل، وخله يرفعه بعد ما تراجعه. كذا يصير عندك موقع حي تحدّثه بالكلام.
