فيديو بالكود: Remotion وHyperFrames للمبتدئين

تقدر تصنع فيديو بكتابة كود بدل برامج المونتاج. تعرّف على Remotion المبني على React وHyperFrames المبني على HTML.

تخيل إنك تطلب من Claude Code فيديو قصير يعرض أرقام مشروعك بحركة حلوة، ويطلع لك ملف فيديو جاهز. هذا ممكن لأن فيه أدوات تخليك تصنع الفيديو بالكود.

ليش فيديو بالكود؟

  • التكرار سهل: تغيّر النص أو الرقم وتطلع نسخة جديدة بدون مونتاج من الصفر.
  • الذكاء الاصطناعي يفهم الكود: تقدر تطلب التعديل بالكلام.
  • قوالب: تسوي قالب واحد وتستخدمه لعشرات الفيديوهات.

Remotion: فيديو بـ React

Remotion أداة تخليك تبني الفيديو كمكونات React. كل فريم في الفيديو عبارة عن صفحة ترسمها بالكود، وتتحكم في الحركة حسب رقم الفريم. بعدها تصدّر الفيديو كملف. موقعها الرسمي remotion.dev وفيه الشرح الكامل.

تبدأ مشروع جديد بهالأمر:

npx create-video@latest

بعدها يفتح لك محرر في المتصفح تشوف فيه الفيديو وتتنقل بين الفريمات.

مهم: راجع شروط الرخصة في موقع Remotion قبل الاستخدام التجاري، لأن لها شروط حسب نوع الاستخدام.

HyperFrames: فيديو بـ HTML

HyperFrames من HeyGen، وفكرتها إنك تكتب الفيديو كصفحة HTML. لو تعرف HTML وCSS، أو حتى لو بتخلي الذكاء الاصطناعي يكتبها عنك، الفكرة قريبة من بناء صفحة ويب عادية، والنتيجة تتحول لفيديو.

أيهم أختار؟

RemotionHyperFrames
الأساسReactHTML
يناسباللي مرتاح مع React ويبغى تحكم كاملاللي يبغى يبدأ من صفحة HTML بسيطة

لو أنت مبتدئ تماماً، جرّب الاثنين بفيديو بسيط واشوف أيهم أريح لك.

خطوات أول فيديو مع Claude Code

  1. سوّ مجلد جديد وافتح فيه Claude Code.
  2. اطلب منه يجهز المشروع بالأداة اللي اخترتها.
  3. وصّف الفيديو مشهد مشهد: النص، المدة، الحركة.
  4. شغّل المعاينة وشوف النتيجة، واطلب تعديلات محددة.
  5. صدّر الفيديو بالمقاس المناسب للمنصة، مثل الطولي للمقاطع القصيرة.
جهّز لي مشروع Remotion جديد في هذا المجلد.
أبغى فيديو طولي مدته 15 ثانية:
المشهد 1 (0-4 ثواني): عنوان كبير بالعربي يقول: وش الجديد عندنا؟
المشهد 2 (4-11 ثانية): ثلاث نقاط تظهر وحدة وحدة بحركة ناعمة.
المشهد 3 (11-15 ثانية): اسم المشروع ودعوة للمتابعة.
النص من اليمين لليسار، وخط عربي واضح، وخلفية هادية.
بعد ما تخلّص قول لي كيف أشغل المعاينة وكيف أصدّر الفيديو.

نصائح للبداية

  • ابدأ بفيديو قصير ومشاهد قليلة، وبعدين زيد.
  • وصّف الحركة بكلمات واضحة مثل: يظهر من تحت، يكبر شوي، يختفي تدريجياً.
  • لو عجبك فيديو، اطلب منه يحوله لقالب تغير فيه النص والألوان بسهولة.
  • راجع الخط العربي واتجاه النص في المعاينة قبل التصدير.

وتذكر إن الفيديو بالكود ما يلغي الإبداع. الفكرة والقصة والتوقيت قرارك أنت، والكود بس طريقة تنفيذ أسرع وأسهل في التكرار.
