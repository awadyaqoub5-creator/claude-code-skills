Claude Code للمبتدئين: أول مشروع لك خطوة بخطوة

ثبّت Claude Code وابنِ أول صفحة ويب بسيطة معه خطوة بخطوة، حتى لو ما عندك خبرة برمجة كبيرة.

Claude Code هو وكيل البرمجة من Anthropic. الفرق بينه وبين المحادثة العادية إنه يشتغل داخل مجلد مشروعك: يقرأ الملفات، يكتب ويعدّل، ويشغّل أوامر. تقدر تستخدمه من الطرفية (Terminal)، أو من تطبيق سطح المكتب، أو من الويب، أو كإضافة داخل محرر الأكواد.

قبل ما تبدأ

  • تحتاج حساب Claude يدعم استخدام Claude Code. تفاصيل الخطط والمتطلبات في docs.claude.com.
  • لو بتستخدم الطرفية، الدليل الرسمي يشرح طرق التثبيت لكل نظام.
  • ما تحتاج تكون مبرمج محترف. يكفي تعرف تفتح الطرفية وتكتب أمر.

التثبيت وأول تشغيل

من طرق التثبيت المعروفة استخدام npm، ويحتاج يكون Node.js مثبت عندك:

npm install -g @anthropic-ai/claude-code

بعدها سوّ مجلد لمشروعك وادخله وشغّل Claude:

mkdir my-first-site
cd my-first-site
claude

أول مرة بيطلب منك تسجل دخول، ويفتح لك المتصفح عشان تربط حسابك. بعدها تكون داخل الجلسة وتقدر تكتب طلبك.

أول مشروع: صفحة لمقهى

اكتب طلب واضح فيه التفاصيل اللي تبغاها:

سوّ لي صفحة ويب وحدة باسم index.html لمقهى اسمه «بن الديرة».
الصفحة بالعربي واتجاهها من اليمين لليسار.
فيها: عنوان ترحيبي، قائمة مشروبات مع الأسعار بالريال،
ساعات العمل، وزر يفتح واتساب.
خلّ التصميم بسيط وألوانه دافئة، وكل شي في ملف واحد.

Claude بيشرح لك وش ناوي يسوي، وبيطلب إذنك قبل ما ينشئ أو يعدل الملفات. وافق، وبعد ما يخلص افتح ملف index.html في المتصفح وشوف النتيجة.

مهم: Claude Code يطلب موافقتك قبل تعديل الملفات أو تشغيل الأوامر. اقرأ وش بيسوي قبل ما توافق، خصوصًا في المشاريع الحقيقية.

عدّل وطوّر

الحلو إنك تكمل معه بنفس الجلسة. جرّب طلبات مثل:

  • «كبّر الخط في الجوال وخلّ القائمة عمودين في الشاشات الكبيرة».
  • «أضف قسم آراء العملاء فيه ثلاث تعليقات».
  • «راجع الصفحة وقل لي وش ممكن يتحسن».

أوامر تحتاجها من أول يوم

الأمروش يسوي
/initينشئ ملف CLAUDE.md فيه معلومات عن مشروعك
/clearيمسح سياق المحادثة ويبدأ من جديد
/compactيختصر المحادثة الطويلة عشان يوفر مساحة
/modelيغير الموديل المستخدم

وش تسوي إذا صار خطأ؟

لا تخاف من الأخطاء، هي جزء طبيعي من الشغل. إذا شي ما اشتغل، انسخ رسالة الخطأ كاملة والصقها لـ Claude، أو اوصف له وش شفت بالضبط. هو بيقرأ الملفات ويحاول يلقى السبب ويصلحه. وإذا المحادثة طالت وصار يتلخبط، استخدم /clear وابدأ طلب جديد واضح.

ابدأ بمشاريع صغيرة مثل هذي، وكل مرة زد التحدي شوي. بسرعة بتلقى نفسك تبني أدوات تفيدك في شغلك.
