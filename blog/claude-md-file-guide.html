ملف CLAUDE.md: علّم Claude عن مشروعك

ملف CLAUDE.md يعطي Claude Code خلفية عن مشروعك في كل جلسة. تعرّف وش تكتب فيه وكيف تسويه بأمر واحد.

كل ما تفتح جلسة جديدة في Claude Code، Claude يبدأ وهو ما يعرف شي عن طريقتك. وش أوامر التشغيل؟ وش أسلوب الكود عندكم؟ وش الأشياء الممنوعة؟ ملف CLAUDE.md يجاوب على هالأسئلة مرة وحدة، وClaude يقرأه تلقائيًا في بداية كل جلسة.

سوّه بأمر واحد

داخل مجلد مشروعك شغّل Claude Code واكتب:

/init

Claude بيقرأ ملفات المشروع ويكتب لك مسودة CLAUDE.md فيها وصف المشروع والأوامر المهمة. راجعها وعدّل اللي تحتاجه، لأن المسودة بداية مو نهاية.

وين ينحط الملف؟

المكانالاستخدام
CLAUDE.md في جذر المشروعمعلومات المشروع، وتشاركه مع فريقك عن طريق git
~/.claude/CLAUDE.mdتفضيلاتك الشخصية اللي تبغاها في كل مشاريعك

وش تكتب فيه؟

  • نبذة عن المشروع: وش يسوي، ولمين.
  • الأوامر: كيف تشغّل المشروع، وكيف تشغل الاختبارات.
  • الهيكل: وين الملفات المهمة.
  • قواعد الكود: التسمية، الأسلوب، المكتبات المعتمدة.
  • الممنوعات: أشياء ما تبغى Claude يسويها.

مثال جاهز

# متجر ريحان

متجر إلكتروني للعطور، الواجهة بالعربي ومن اليمين لليسار.

## الأوامر
- تشغيل المشروع: npm run dev
- الاختبارات: npm test
- فحص الكود: npm run lint

## الهيكل
- src/pages: الصفحات
- src/components: المكونات المشتركة
- src/lib: الدوال المساعدة

## القواعد
- كل النصوص الظاهرة للمستخدم بالعربي
- استخدم المكونات الموجودة قبل ما تسوي مكون جديد
- شغّل الاختبارات بعد أي تعديل على منطق الدفع

## ممنوع
- لا تعدل ملفات الإعداد الخاصة بالنشر بدون ما تسألني
- لا تضيف مكتبة جديدة بدون موافقة

نصائح تخلي الملف فعّال

  • خلّه مختصر: الملف يتحمّل في كل جلسة، فكل سطر زايد ياخذ من مساحة السياق.
  • كن محدد: «استخدم مسافتين للمسافة البادئة» أوضح من «اكتب كود مرتب».
  • حدّثه باستمرار: إذا لاحظت Claude يكرر نفس الغلطة، أضف قاعدة تمنعها.
  • اطلب من Claude يحدّثه: قل له «أضف هالقاعدة لملف CLAUDE.md» وهو يعدله.
تنبيه: لا تحط كلمات مرور أو مفاتيح API داخل CLAUDE.md، خصوصًا إذا الملف مرفوع على git ويشوفه غيرك.

علامات إن ملفك يحتاج تحديث

  • Claude يسأل عن أمر التشغيل كل مرة.
  • يستخدم مكتبة غير اللي يعتمدها فريقك.
  • يكتب نصوص بالإنجليزي في واجهة المفروض تكون عربية.
  • يعدل ملفات المفروض ما يقرب منها.

كل علامة من هذي تعني إن فيه قاعدة ناقصة. أضفها مباشرة وأنت متذكر.

ملف CLAUDE.md الزين يوفر عليك شرح متكرر، ويخلي نتائج Claude أقرب لطريقة شغلك من أول طلب.
