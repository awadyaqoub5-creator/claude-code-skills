الأدواتطريقة التركيب

كل أدوات Claude في صفحة وحدة

تطبيقات Claude ومزاياه والموديلات، وكل أدوات وسكلز وأوامر Claude Code. كل وحدة مشروحة بسطر واضح، ومعها مثال تنسخه وتجربه على طول.

ما لقينا شي بهالكلمة. جرّب كلمة ثانية أو اختار "الكل".

طريقة التركيب والاستخدام

تشغّل سكل

اكتب / واسم السكل في Claude Code، أو اطلب الشي بكلامك العادي وClaude يختار السكل المناسب لحاله.

/frontend-design
# أو بكلامك:
سوّ لي صفحة هبوط لمتجر عطور

تسوي سكل خاص فيك

السكل مجلد فيه ملف SKILL.md. حطه في ~/.claude/skills/ عشان يشتغل في كل مشاريعك، أو في .claude/skills/ داخل المشروع.

---
name: my-skill
description: متى يستخدمه Claude
---
اكتب هنا التعليمات خطوة بخطوة

تضيف إضافات (Plugins)

الإضافة حزمة فيها سكلز وأوامر وagents. تضيف المتجر مرة وحدة، وبعدها تنزّل منه اللي تبغاه.

/plugin marketplace add <owner/repo>
/plugin install <plugin-name>

تربط أدوات خارجية (MCP)

MCP يربط Claude Code بخدمات ثانية مثل GitHub وFigma وقواعد البيانات. بعد الربط تصير أدواتها متاحة لـ Claude.

claude mcp add <name> -- <command>
/mcp   # تشوف المربوط وحالته
