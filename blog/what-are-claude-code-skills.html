وش هي السكلز (Skills) في Claude Code وكيف تركّبها؟

السكلز مجلدات فيها تعليمات يستخدمها Claude لما يحتاجها. تعرّف وش هي، وين تنحط، وكيف تركّبها بأمان.

تخيل إن عندك موظف شاطر، وكل ما احتجت شغلة معينة تعطيه دليل مكتوب يمشي عليه. السكلز في Claude Code نفس الفكرة: دليل جاهز يفتحه Claude لما تكون المهمة تحتاجه.

وش هي السكل بالضبط؟

السكل عبارة عن مجلد فيه ملف اسمه SKILL.md. أول الملف فيه جزء YAML بسيط يحدد اسم السكل ووصفها، وبعده التعليمات نفسها. وممكن يكون في المجلد ملفات ثانية مثل قوالب أو سكربتات تستخدمها السكل.

الشي الذكي إن Claude ما يقرأ كل السكلز كاملة من البداية. يشوف الاسم والوصف، وإذا طلبك يناسب سكل معينة يفتح تعليماتها ويشتغل عليها. عشان كذا الوصف مهم جدًا.

وين تنحط السكلز؟

المكانلمين
~/.claude/skills/سكلز شخصية، متاحة لك في كل مشاريعك
.claude/skills/ داخل المشروعسكلز خاصة بالمشروع، وتقدر تشاركها مع فريقك عن طريق git

وشكل المجلد يكون كذا:

~/.claude/skills/
  meeting-notes/
    SKILL.md
    template.md

طرق التركيب

1. يدويًا

انسخ مجلد السكل كامل وحطه في واحد من المكانين فوق. تأكد إن ملف SKILL.md موجود مباشرة داخل مجلد السكل، مو داخل مجلد فرعي ثاني.

2. عن طريق البلقنز (Plugins)

بعض السكلز توصلك ضمن بلقن. تضيف المتجر (Marketplace) أول، بعدين تركّب البلقن:

/plugin marketplace add <owner/repo>
/plugin install <plugin-name>

تقدر تشوف أمثلة رسمية على السكلز في github.com/anthropics/skills.

تأكد إنها اشتغلت

افتح جلسة جديدة واسأل Claude مباشرة:

وش السكلز المتاحة عندك الحين؟ واشرح لي باختصار متى تستخدم كل وحدة.

بعدها جرّب طلب يناسب وصف السكل، وشوف هل Claude استخدمها.

أمان: السكل ممكن تحتوي سكربتات تنفذ أوامر على جهازك. ركّب بس من مصادر تثق فيها، واقرأ محتوى SKILL.md والملفات اللي معه قبل الاستخدام.

السكل ولا CLAUDE.md؟

متى تحتاج سكل؟

لو لاحظت نفسك تكتب نفس التعليمات الطويلة لـ Claude أكثر من مرة، هذي إشارة واضحة. أمثلة: صياغة عروض أسعار بقالب شركتك، كتابة محاضر الاجتماعات بشكل موحد، أو مراجعة الكود حسب قواعد فريقك. حوّل هالتعليمات لسكل مرة وحدة، وخلّ Claude يرجع لها لحاله كل ما احتاجها. وفي المقال الجاي نشرح كيف تسوي سكل خاصة فيك من الصفر.

ملف CLAUDE.md يتحمّل في كل جلسة داخل المشروع، فهو مناسب للمعلومات العامة اللي Claude يحتاجها دايم. السكل مناسبة لمهمة محددة لها خطوات واضحة، مثل كتابة تقرير بصيغة ثابتة أو مراجعة كود بطريقة معينة. Claude يفتحها بس لما يحتاجها، فما تزحم السياق.
